YouTube 视频快捷入口

视频右上角「记一笔」会保存当前时间附近的字幕。非中文引用会将附近字幕发送给 DeepSeek，自动补齐中文译文。开启后，每次打开 YouTube 自动显示；也可在视频页点击工具栏Clips图标，仅在本次页面使用。

YouTube 字幕 · Supadata

点击读取时，仅发送视频链接给 Supadata。使用原生字幕；不会自动转录视频。

获取 API Key ↗

默认随浏览器关闭而清除。Key 不上传到笔记库。

阅读辅助 · DeepSeek

使用你自己的 DeepSeek 账户。Overview 基于全部已保存字幕；翻译仅发送当前页缺失段落。摘要与理解使用你确认的页面上下文，均由你手动点击开始。
