# Clips

在浏览器中边读边记，把摘录、想法、截图和视频引用保存到自己的文件夹。

Clips 是一个 Chrome 扩展，包含侧边栏和本地笔记库。**不需要 ChatGPT 账号、不需要部署服务器。** 普通记录无需 API Key；AI 功能使用你自己配置的 DeepSeek / Supadata 账号。

[下载安装包](https://github.com/baijianyu1024-cmd/clips/releases/latest/download/clips-chrome-extension.zip) · [所有版本](https://github.com/baijianyu1024-cmd/clips/releases) · [隐私说明](PRIVACY.md) · [自行二次开发](DEVELOPMENT.md)

## 功能

- **边读边记**：摘录原文、写想法、粘贴或上传图片；切换网页时保留当前笔记，保存到不匹配的文章前再次确认。
- **笔记库**：全部记录打平浏览，或按篇查看；搜索、标签、待阅读、归档、内容发布时间和后续补充。
- **Markdown**：基本格式、列表、链接、表格、行内代码与代码块，编辑时直接渲染。
- **基于笔记提问**：检索笔记与已保存的原文片段，多轮追问、核对引用，再整理成新笔记。
- **核心摘要**：结合当前可读取的页面内容、阅读记录和补充信息生成，支持修改及重新生成。
- **理解 / 翻译**：支持引用、图片和多轮追问；可将问答整理成想法，经确认后保存。
- **YouTube 阅读**：获取原生字幕、生成 Overview、双语关键引用、字幕翻译、章节跳转与播放跟随；视频中可快速保存当前上下文的引用。
- **本地资料库**：笔记、图片与字幕直接写入所选文件夹，支持完整备份和 Markdown 导出。

## 安装（Windows / macOS）

### 让 Agent 帮你安装

可以把本仓库链接交给能访问本机文件、执行命令的 Agent（例如本地运行的 Codex），让它按照本说明协助安装。能否代为操作 Chrome 取决于 Agent 的浏览器工具及授权；加载扩展、授权笔记文件夹等步骤可能需要你亲自点击。只提供聊天或仅在云端运行、未连接本机的 Agent，可以提供操作指导，不能直接安装到你的电脑。

复制下面这段话，连同仓库链接一起发给 Agent：

> 请帮我安装 [Clips](https://github.com/baijianyu1024-cmd/clips)，用于日常使用。先阅读 README，识别我的 Windows 或 macOS 环境，优先下载最新 Release 中的 `clips-chrome-extension.zip`，解压到长期保留的目录，再协助我加载到 Chrome，并设置独立的本地笔记文件夹。需要我手动操作时，请明确告诉我步骤。安装完成后，检查侧栏能否打开，并陪我保存、重新打开一条测试笔记。API Key 我会自己在插件设置里填写。

普通安装使用不需要 Fork、Git 或 Node.js，也不需要从源码构建；想二次创作时再参考下方的「自行二次开发」。

### 手动安装

1. 使用桌面版 Chrome，下载上方的 `clips-chrome-extension.zip`。请选这个附件，而不是 GitHub 自动生成的 `Source code.zip`。
2. 解压到一个长期保留的文件夹，例如 `Documents/Clips/extension`。不要在 ZIP 压缩包里直接打开。
3. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择刚解压的 `clips-chrome-extension` 文件夹；其中应直接包含 `manifest.json`。
5. 安装后打开本地笔记库，选择一个**单独的空文件夹**保存笔记。插件文件夹与笔记文件夹应分开。
6. 将 Clips 固定到工具栏；打开文章或视频，点击 Clips 图标，在侧边栏中手动开始笔记。

建议使用最新版 Chrome；扩展声明的最低版本为 116。当前以桌面 Chrome 为目标，尚未完成 Windows 真机和其他浏览器的兼容性实测。它不是 Chrome Web Store 安装包，首次需要按上述步骤加载，也不会自动更新。

### 更新

先保存草稿并做资料库备份，再下载新版 ZIP，将文件覆盖到**原插件目录**。回到 `chrome://extensions`，点击 Clips 卡片上的「重新加载」，重新打开侧栏；如需 YouTube 页面内入口，请刷新视频页面。不要先卸载插件，以免丢失本机设置与未保存的草稿。

### AI 设置

在侧栏或笔记库打开「阅读设置」，点击对应输入框旁的「获取 API Key」前往官方控制台：[DeepSeek](https://platform.deepseek.com/api_keys) · [Supadata](https://dash.supadata.ai/)。填写 Key 后保存并授予对应服务权限：

| 能力 | 需要的服务 |
| --- | --- |
| 普通笔记、图片、标签、导出 | 无 |
| 核心摘要、理解与翻译 | DeepSeek |
| 获取 YouTube 字幕 | Supadata |
| YouTube Overview、字幕与引用翻译 | Supadata + DeepSeek |

模型名称可在设置中修改；当前默认 `deepseek-flash`。图片理解要求模型支持图像输入，请使用服务商当前支持的模型。模型可用性、配额及 API 费用由各服务商决定。

Key 默认仅保留到浏览器会话结束，勾选「记住到本机」后才保存在插件本机存储中；不会写进笔记文件夹或 Markdown 导出。不提供公共 Key，也不要求把 Key 写入源码、`.env` 或 GitHub。

## 数据与迁移

资料库文件夹结构：

```text
My Clips/
  clips.json          # 笔记、标签和记录
  images/             # 图片
  transcripts/        # 字幕、Overview 和翻译
  backups/            # 上一次修改前的数据
  README.txt
```

换电脑时，先保存所有草稿，使用「资料库与备份 → 完整备份到文件夹」，或关闭编辑后复制整个资料库。在新电脑安装 Clips，再选择复制过去的资料库文件夹。Windows 和 Mac 使用同一种数据格式；API Key 和文件夹权限需要在新电脑重新配置。

笔记的正式数据保存在文件夹中。浏览器仍保存文件夹授权、设置、缓存和未提交的草稿，所以迁移前务必先保存。**此版本没有云同步，不支持多台电脑同时编辑同一个网盘文件夹。** Markdown 导出适合阅读和分享；完整恢复请保留整个原始资料库。

## 边界

- 仅在用户触发时读取已授权页面中的可获取内容；飞书、画板、懒加载页面和受限内容不保证完整提取，无法读取时会提示范围。
- YouTube 字幕依赖 Supadata 的原生字幕接口；没有可用字幕的视频不会自动转录音频。
- 插件设置页、浏览器内置 PDF 阅读器等页面可能不允许注入脚本。
- 本仓库仅包含可独立运行的本地版；不包含作者个人云端站点、托管配置、笔记数据或私人部署历史。

## 自行二次开发

**原仓库由作者维护。** 开源不代表开放原仓库的写入权限。你可以点击 GitHub 上的 **Fork** 将项目复制到自己的账号，再克隆自己的仓库并独立修改、发布；这些改动不会影响原仓库或作者的笔记。也可以直接下载源码进行本地修改。

需要 Node.js 22.13 或更新版本与 npm：

```sh
git clone https://github.com/baijianyu1024-cmd/clips.git
cd clips
npm ci
npm test
npm run package
```

产物在 `dist/clips-chrome-extension/` 与 `dist/clips-chrome-extension.zip`。修改源码后重新打包，在扩展管理页加载或重载该目录即可。打包流程会重新构建富文本编辑器，并生成 `SHA256SUMS.txt`。

| 目录 | 内容 |
| --- | --- |
| `extension/` | Manifest V3 扩展、侧栏、本地笔记库及存储适配器 |
| `editor/` | Tiptap / ProseMirror 编辑器源码 |
| `scripts/` | 编辑器构建、打包与公开内容检查 |
| `tests/extension/` | 自动化测试，使用虚构数据和临时文件夹 |

代码中的 `adapter.cloud` / `CLOUD` 是历史命名的资料库接口；本发行版只路由到本地文件夹，不发送到笔记云服务。

## 0.13.0 · 笔记对话

在笔记库打开「对话」，可跨笔记提问、继续追问、对比观点或整理提纲。可选择全部笔记或指定笔记；沿用插件的 DeepSeek 配置，只有发送问题时才调用 AI。

- 回答上方的「查看材料」打开弹窗：「本轮参考」是实际发送给这次回答的材料；「全部检索」是截至该轮找到的全部材料，并标记未用于本轮的内容。
- 引用数字对应一段材料（想法、原文片段、图片或字幕片段），同一篇笔记可有多个编号。点击数字定位具体片段；同一片段跨轮保留编号。
- 「整理成笔记」可选本轮或整段对话，先生成可编辑的笔记预览，确认后保存；同时保留问题、材料快照和回到对话的链接。
- 原文来自已保存的副本、字幕，以及在原文页使用总结／理解时已读取并留存的文字和可见图片。只有当前网页与正在记录的笔记匹配时才留存；不自动翻页、滚动或读取后台页面。飞书等页面通常只有已加载片段，不能视为全文。
- 第一版使用中英文关键词检索、查询改写、按笔记分散选材和相邻原文补充；尚未使用向量数据库或联网搜索。每次最多 300 篇笔记，最多提供 18 段 / 22,000 字 / 4 张图片。图片先按名称与关联记录匹配，选中后才交给视觉模型；未实现图片全文索引。
- 每段事实性回答必须引用本轮提供的材料；推断与证据不足会标明。程序核对引用是否属于本轮材料，但不能保证模型的解释一定正确，请核对原文。
- 最近 6 轮问答用于理解追问，历史回答本身不作为原文证据。单个对话最多 20 轮、累计 240 段材料；达到上限后先整理为笔记，再新建对话。

本地模式：`conversations/` 保存对话及材料快照，`materials/` 保存获取过的原文片段，`images/` 保存图片，`transcripts/` 保存字幕；笔记与标签仍在 `clips.json`。迁移到 Windows 或 Mac 时复制**整个资料库文件夹**。浏览器仅保留设置、授权和待重试草稿。已保存的对话／整理笔记包含当时的材料副本；之后修改或移除原笔记不会回写这些历史快照。首版尚无对话删除界面。

发送问题会把选中的材料和必要对话历史交给 DeepSeek；未选中的其他笔记不会随回答请求上传。查询改写会提供最新问题与最近对话的简短片段。API Key 留在插件内，不写入资料库、备份或 GitHub。

### 0.14.2：自动暂存与笔记预览

- 日常记录统一显示「已自动暂存」，存储失败会明确提示。
- AI 生成待确认的内容统一为「笔记预览」。对话整理的笔记预览、理解问答整理的想法预览，以及手动修改的内容，都会在本机自动暂存；关闭或刷新后可继续编辑。
- 正式保存成功后清理对应预览；保存失败可直接重试，不必重新生成。
- 对话输入框中的未发送问题也会暂存；精简空状态和重复说明。

暂存内容位于当前浏览器，按资料库及对话／来源页面隔离，不自动同步到其他设备，也不包含在资料库文件夹备份中。迁移、卸载插件或清理浏览器数据前，请先正式保存需要保留的内容。理解／翻译的临时问答仍在切换页面或关闭侧栏后清空；已整理出的笔记预览会保留。


### 界面与版本对齐

从 0.15.0 起，本地笔记库使用 `ui/app/` 中的共享界面：导航、全部记录/按篇笔记、筛选、标签管理、详情编辑、摘要、图片和字幕阅读。`extension/library-platform.js` 只负责文件夹请求、图片和页面地址适配。对话、AI、字幕和侧栏仍使用相同的功能模块。

修改后运行 `npm run build`、`npm test`、`npm run check:release`、`npm run package`。维护者还可运行 `node scripts/check-parity.mjs --reference <参考源码根目录>`，核对两份源码的共享界面和功能模块；存储连接差异单独记录在 `ui/parity.json`，不能靠忽略整个文件掩盖功能改动。

升级保留原插件目录与资料库，不要卸载。若旧版笔记库有未保存内容，可在「资料库与备份 → 旧版未保存内容」恢复。已保存笔记、图片和字幕仍在原文件夹。
